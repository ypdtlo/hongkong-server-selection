## 为什么香港节点会被单独拎出来选

香港机房对国内用户的价值集中在两点。一是不需要备案，域名解析过去就能直接访问，不存在等待审核的周期；二是物理距离近，面向中国大陆和亚太地区访问时延迟通常比美国、欧洲节点低一个档次。

雨云的香港节点属于典型的高带宽成本结构：带宽给的额度比国内机房大方，但流量是要算钱的，用完会被限速。这一点在后面的计费部分会展开说。

顺带说明一下雨云本身的背景，因为它直接影响你的支付和售后体验：雨云成立于 2018 年，是国产云计算服务商，持有工信部颁发的《增值电信业务经营许可证》ISP 证、IDC 证、CDN 证，支持支付宝和微信付款，也支持 7 天内无理由退款（每个账号上限 3 次）。这几条在多个渠道的公开信息中是一致的。

## 雨云香港的几个区，线路和带宽策略都不一样

这是选香港服务器时最容易被忽略的一层。同一个“中国香港”，不同区域跑的是不同网络：

| 区域 | 线路方向 | 延迟表现 | 带宽特点 |
| --- | --- | --- | --- |
| 香港二区 | 三网优化 / 移动 CMI 方向 | 大陆访问较低，实测三网均值约 45ms 量级 | 最高约 100Mbps，分流量叠加型与不限流量型 |
| 香港三区 | 三网直连（CN2 + CMI + CUG） | 延迟低，适合国内访问为主 | 带宽偏低（常见 5M～10M 档） |
| 香港四区 | IIJ 大带宽 / 混合软银线路 | 实测约 100～110ms，回程部分绕日本 | 大带宽，主打移动方向优化 |
| 香港五区 | 纯国际线路，亚太混合接入 | 面向海外与亚太访问更顺手 | 最高 1Gbps，自带香港原生 IP |

几个实际的取舍：

- 访客主要在中国大陆，尤其是电信用户 —— 优先看香港三区和香港二区，这两条线的回程走直连骨干，延迟和丢包表现明显更稳。
- 业务面向东南亚、港澳台或者海外平台 —— 香港五区的国际大带宽更合适，1Gbps 峰值对下载分发、跨境后台这类场景更实用。
- 只是搭博客、企业官网、小型 WordPress —— 二区或三区的低配起步就够，没必要为线路多付钱。
- 需要 Windows 或 macOS 镜像 —— 这并不是所有区都支持，公开资料显示 macOS 只有香港二区和香港四区可选，下单前先确认镜像列表。

## 流量叠加型 和 不限流量型，到底选哪个

雨云香港云服务器有个不太常见的设定：同一个配置，你可以选“大带宽 + 限流量”，也可以选“小带宽 + 不限流量”，两者价格相同。选错方向，体验差别很大。

**流量叠加型**：带宽给得高（常见 200Mbps 到 1Gbps），每月配固定流量额度。好处是突发流量、下载、上传、批量分发这类场景跑得快；代价是额度用完之后会被限速到 5Mbps。还有一个细节值得记住——**当月没用完的流量可以叠加到之后使用，不是月末清零**，所以流量消耗波动大的业务，用流量型反而更划算。

**不限流量型**：带宽砍下来（同一配置可能只有流量型的十分之一甚至更低），但不用担心额度。适合长期低速率、持续在线的场景，比如接口服务、监控、爬虫调度、小型代理中转、常驻后台。

判断方法很直接：你的业务是“偶尔需要跑满高速”还是“常年维持在低速率”。前者选流量型，后者选不限流量型。如果你自己都说不准，先用月付跑一个月，看后台的流量曲线再决定。

流量用完之后想恢复高速，需要另外购买流量包，不同区域的流量包定价不一致，这一项建议在购买页确认，而不是凭印象估算。

## 容易被忽略的三项附加成本

基础月付价格之外，还有几个会实打实加钱的地方：

**独立 IP**。默认自带 1 个 IPv4，之后每多加一个按 5 元/个/月计。需要多站多 IP 的要注意累计成本。

**高防 IP**。香港节点可选防御型 IP，公开信息显示香港移动高防约 40 元/月，国际高防约 30 元/月，裸金属机型的高防 IP 报价更高。不是所有区都能加高防，选区域的时候要一起确认。

## 常见问题

**香港二区和香港三区怎么选？** 二区带宽给得更大（最高可到 100Mbps 量级），三区带宽偏低但三网直连更彻底。国内三网访问都要兼顾、又需要一定带宽的，先测二区；对延迟和稳定性极度敏感、带宽需求不高的，看三区。

**月付还是年付？** 年付 7 折的力度不小，但不建议对没实测过的机型直接年付。先用月付或 1 元试用跑一周，记录晚高峰的延迟、CPU 和内存占用、流量增长曲线，数据没问题的机型再转年付，这一条经验比省下来的钱更值。

**香港服务器的 IP 是原生的吗？** 香港五区（国际线路）自带香港原生 IP，对部分流媒体、AI 平台和港区服务的兼容性更好；其他区的 IP 纯净度表现不一，如果你的业务对 IP 归属敏感（比如跑特定平台账号、需要港区内容解锁），下单前把这一项单独问清楚客服。

**支持什么付款方式？** 支付宝和微信都可以，人民币计价结算。
